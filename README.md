# 定石モチベ

リバーシの定石を、曜日ごとに出題して覚えるためのドリル（スマホ向けWebアプリ）。

- 盤をタップして「次の一手」を答える
- まちがえず最後まで解ききると★が入り、その定石のカードが光る
- おぼえた定石の系統にあわせて「モチ」が増える（全116体）

## 中身

`index.html` 1枚で完結しています。ビルドは不要で、そのままブラウザで開けます。

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体（CSS・JavaScript・定石データすべて） |
| `sw.js` / `manifest.webmanifest` | ホーム画面に追加して使うための設定 |
| `編集ガイド.html` | どこを直せば何が変わるかの手引き |

## 定石データの出どころ

収録している196本は、次の公開情報から手順を写したものです。全手がルール上打てる手かどうかは、読み込み時に自動で検査しています。

- [オセロ･リバーシの勝ち方、必勝法](https://bassy84.net/zyouseki)（抜歯ぃさん）
- [オセロクエスト 戦法一覧](https://note.com/mjulin/n/n30822fb12a26)（mjulin さん）
